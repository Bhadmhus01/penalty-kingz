# Naija Penalty Kingz

Independent Lagos-inspired football penalty game with a Canvas client and zero-dependency Node.js ESM backend. The Lagos Life name appears only to identify the intended hosting platform; this project does not claim platform endorsement or acceptance.

Run `npm start`, then open http://localhost:3000. Set `?dev=1` to show the developer sandbox checklist. The app includes a low-data PWA shell, visible guest/Vatar account and cloud-save status, `?screen=` hub entry routes, Lagos-time daily challenges, a signed-results leaderboard, local history, and shareable rival challenge cards. Real matchday dates are operator-configured; no live fixture feed is claimed. See `LAGOS_LIFE_SUBMISSION_GUIDE.md` for deployment, Vatar secrets, Games hub handoff, fixture schedule configuration, and catalog setup.
