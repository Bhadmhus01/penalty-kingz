# Naija Penalty Kingz

Lagos Life mobile-first football penalty game with Canvas client and zero-dependency Node.js ESM backend.

Run `npm start`, then open http://localhost:3000. Set `?dev=1` to show the developer sandbox checklist. The app includes a low-data PWA shell, guest/Vatar-verified progress sync, Lagos-time daily challenges, a signed-results leaderboard, local history, and shareable rival challenge cards. Real matchday dates are operator-configured; no live fixture feed is claimed. See `LAGOS_LIFE_SUBMISSION_GUIDE.md` for deployment, Vatar secrets, fixture schedule configuration, and catalog setup.
